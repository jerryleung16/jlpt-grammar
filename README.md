# JLPT Grammar SRS

A modern Next.js starter for a JLPT grammar formulaic system with an SRS-style practice mode.

## Run locally

```bash
npm install
npm run dev
```

## Routes

- `/` — landing page
- `/practice` — swipe-based flashcard practice view

## Main stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- ts-fsrs
- TinaCMS-ready content structure
